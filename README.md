# Comeback App — Official Downloads

This repository exists only to distribute official release builds of the Comeback app.

It does **not** contain any source code.

---

## 📱 What is Comeback?

Comeback is a focused self-improvement and discipline platform designed to help users build consistency, clarity, and long-term progress through a calm and structured digital environment.

This repository is the public distribution point for:

- Android app builds (`.apk`)
- Web version
- Version history and changelogs

---

## ⬇️ Download

Go to the **Releases** section to download the latest version:

➡️ **Releases → Latest**

Each release includes:
- Version number
- Changelog
- Downloadable build files
